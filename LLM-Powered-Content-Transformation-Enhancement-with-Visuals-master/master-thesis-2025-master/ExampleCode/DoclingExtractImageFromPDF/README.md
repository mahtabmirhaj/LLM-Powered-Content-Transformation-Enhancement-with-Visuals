# How to Extract Images from PDF Files

## Using Docling

Code example: https://ds4sd.github.io/docling/examples/export_figures/

In the example code, you find five ways to extract images from a PDF file:

- Save the whole page as image
- Save figures and tables as images
- Save the page as markdown with embedded pictures
- Save the page as markdown with externally referenced pictures
- Save as HTML with externally referenced pictures
