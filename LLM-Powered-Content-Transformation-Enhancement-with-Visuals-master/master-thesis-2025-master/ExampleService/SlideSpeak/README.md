# SlideSpeak

Create presentations with AI, summarize PowerPoint or Word documents and much more.

- https://slidespeak.co/

## Create PPT from pdf

1. Download pdf file e.g. from https://arxiv.org/pdf/2501.12948
2. Go to https://slidespeak.co, and press "Try Now" button
3. On the page, click on "Create Prentation with AI"
4. The click on "From a document" and the "Click to upload"
5. For user prompt, use something like "Summarize the key points from the input PDF file, and create a presentation based on the summary"
6. Continue to create presentation
7. Download presentation (You need Premium subscription to download the file, but you can brown online and take screenshot for each page)
